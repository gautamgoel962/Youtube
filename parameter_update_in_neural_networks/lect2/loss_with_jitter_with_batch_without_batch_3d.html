Epoch loss averages over the entire dataset each epoch, producing a smooth surface.
Batch loss is computed per mini-batch — each batch samples different data, so gradients vary, creating the jagged 3D surface with visible noise ridges. The extra Z-axis represents a parameter dimension, showing how loss varies across parameter space.
